
## Overview
**§§§§§§** is a student Product Design & MVP project.  
The goal of this project is to imagine, design, and prototype a focused social web application addressing a clearly identified user problem.

This repository contains both:
- the **Product Design documentation**
- the **minimal functional MVP**

The project follows a structured product design process: research, problem framing, UX design, prototyping, testing, prioritization, and development.

---

## Project Goals
- Identify a real user problem based on research and interviews  
- Design a coherent and justified user experience  
- Build a minimal MVP demonstrating the main user flow  
- Document the entire product design process
